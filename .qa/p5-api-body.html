Response shape

Every registry file uses the same envelope. Record fields vary by registry; fields the source did not state are null, empty, or absent.

Field Type Notes
_metaobjectRegistry name, label, API version, generation date, record and category counts, source, and last-verified date.
recordsarrayCatalog records. Arrays are stable for a given generated file.
idstringStable identifier used by the page deep links (#tool/<id>, #model/<id>, #resource/<id>).
name, descriptionstringDisplay name and the description carried over from the source.
categorystringNormalized catalog category. source_category keeps the source label.
official_urlstringPublisher URL recorded in the catalog. Always inspect before relying on it.
license, pricingstring | nullOnly the stated value; null when the source is silent.
tagsstring[]Search and display tags from the catalog.
evidence[label, url][]Source links used to verify the record.
verified, statusstringVerification date and lifecycle status recorded in the catalog.
Registry-specificvariesTools: org, platform, hosting. Models: publisher, params, context_k, modalities. Resources: resource_subtype, programming_languages, api_url, documentation_url.

Reading a file

When these files are served over HTTP from the site root, a static fetch returns the JSON envelope. Nothing is mutated and there are no write endpoints.

const res = await fetch('api/tools.json');
const { _meta, records } = await res.json();
console.log(_meta.count, records.map((r) => r.id));
