## 1. Architecture

- Static HTML/CSS/vanilla JavaScript site. No framework, bundler, or runtime
  database is used for page rendering.
- Tailwind is loaded from a CDN with an inline configuration in `index.html`.
  Shared overrides live in `assets/site.css`.
- Registry data is published as browser globals:
  - `window.AI_TOOLS` — `data/ai-tools.js`
  - `window.AI_MODELS` — `data/ai-models.js`
  - `window.DEVELOPER_RESOURCES` — `data/developer-resources.js`
- JSON mirrors are shipped under `api/` and regenerated by
  `.qa/api-build.js` from the `data/*.js` registries.
- The root-level `ai-resources-1000.json`, `ai-models.json`, and
  `developer-resources.json` are the source snapshots from which the data
  modules were originally assembled.

## 5. Identifier, schema, and routing conventions

- IDs are kebab-case slugs derived from product names (for example
  `chatgpt`, `gemini-1-5-pro`, `n8n`).
- IDs are unique within each registry; canonical references are prefixed
  `tool:`, `model:`, or `resource:` in cross-registry data.
- Detail views are client-side hash routes:
  - `ai-tools.html#tool/<id>`
  - `models.html#model/<id>`
  - `developer-resources.html#resource/<id>`
- Registry pages read the browser-global arrays directly:
  - `ai-tools.html` uses `window.AI_TOOLS`.
  - `models.html` maps `window.AI_MODELS` into a presentation adapter
    (`MODELS_DATA`).
  - `developer-resources.html` uses `window.DEVELOPER_RESOURCES`.
- All three pages provide text search, category pills, facet filters, sorting,
  pagination, and a detail overlay. Adding a record to the data module is
  sufficient for it to appear in search, filters, and detail routing.

## 9. Constraints carried into the implementation

- Preserve the existing static architecture, design tokens, and registries.
- Nexus Spotlight is an editorial surface, not a fourth registry.
- Every Spotlight item must resolve to a canonical registry record.
- Existing canonical records must not be overwritten, renamed, or duplicated.
- New records require primary official evidence.
- No deploy, push, or publication without explicit authorization.
