Catalog Console

Terminal

A read-only console over the local registry datasets. It parses a fixed command allowlist and prints catalog records.

READ-ONLY · ALLOWLIST
shield

This is not a system shell.

It cannot execute shell commands, evaluate JavaScript, read local files, or call external services. Commands only query the three catalog datasets already loaded on this page.

catalog://terminal LOCAL DATA · NO NETWORK
$

Allowed commands

Every command below is implemented in the page. Unknown commands are rejected without evaluation.

Command Action
helpList the allowlisted commands.
statsRecord and category counts for each registry.
list <registry>Show record IDs and names. Registries: tools, models, resources.
search <term>Search names, descriptions, categories, tags, and publishers across all registries.
show <id>Print the stated fields for one record.
categories <registry>Category counts, for one registry or all three.
open <id>Open the record's page and deep-link view.
clearClear the output area.

Command history is available with the up and down arrow keys. The console does not store input outside this page.
